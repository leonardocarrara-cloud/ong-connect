# ONG Connect

Projeto acadêmico demonstrativo de uma plataforma para organizações do terceiro setor.

## Recursos demonstrados
- Design System com variáveis CSS
- CSS Grid de 12 colunas
- 5 faixas responsivas
- Flexbox
- Menu hambúrguer
- Estados hover, focus, active e disabled
- Validação visual de formulário
- Badges, alertas, toast e modal

## Como executar
Abra `index.html` em um navegador moderno. Não é necessário instalar dependências.

## Capturas para a atividade
A seção “Estados semânticos” exibe badges e alertas. Clique em “Exibir toast de sucesso” para capturar o toast e em “Quero ser voluntário” para capturar o modal.
